# Yogaverse

Yogaverse is a beginner-friendly yoga website built using HTML and CSS. The site emphasizes a clean, calming layout and straightforward navigation so new practitioners can easily find basic poses, breathing exercises, and practical tips.

## Features
- Built with semantic HTML and modular CSS  
- Beginner-focused content (poses, breathing exercises, tips)  
- Clean, user-first layout with intuitive navigation  
- Lightweight and easy to customize or extend

## View locally
Open `index.html` in your browser (or host the site on GitHub Pages / any static host).
